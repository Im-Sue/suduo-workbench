# Windows 11 实机验收清单（桌面应用）

用户在自己的 Windows 11（x64）上按顺序走一遍；每项记「通过 / 不通过 + 截图或现象」。CI 已在 `windows-2025` 构建机上自动跑过安装 → 冒烟 → 卸载，这里验的是真人会碰到的部分。

准备：从草稿 Release（或正式 Release）下载 `SuDuo-Setup-<版本>-x64.exe` 和 `SHA256SUMS.txt`；准备一个 git 仓库做项目目录；团队服务器地址与账号。

## 安装与首次启动

1. 下载后核对 SHA256（PowerShell：`Get-FileHash .\SuDuo-Setup-<版本>-x64.exe`），与 `SHA256SUMS.txt` 一致。
2. 双击安装：SmartScreen 提示「Windows 已保护你的电脑」→「更多信息」→「仍要运行」。不要求管理员权限，装完自动打开 SuDuo。
3. 开始菜单、桌面各有一个 SuDuo 快捷方式；装在 `%LOCALAPPDATA%\Programs\suduo-desktop`。
4. 首启向导：连接服务 → 登录 → 环境检查（Codex、Git 有一项；没装 Git 时给出 Git for Windows 的安装提示，能继续）→ 连接 Agent → 关联项目代码 → 完成。

## 日常使用

5. 在一条需求上开工，跑一轮 Codex 会话：能在项目里执行 `git status`、`node -v` 这类命令（用的是系统与用户的环境变量）。
6. 关窗：首次关窗弹出「SuDuo 仍在后台运行」通知；通知区域有 SuDuo 图标；进行中的会话不中断。
7. 单击通知区域图标重新打开窗口；右键菜单里有「打开 SuDuo」「在浏览器中打开」「打开日志目录」「退出 SuDuo」。
8. 「设置 → 通知」打开系统通知；让一个会话在后台等你确认：右下角弹出系统通知，点它把 SuDuo 窗口带到前面。
9. 「设置 → 桌面应用」：打开开机自启 → 注销重登（或重启）→ SuDuo 在后台启动、只有通知区域图标、没有弹窗口；再到「设置 → 应用 → 启动」里把它关掉，回到 SuDuo 的设置页，开关显示为关。
10. 「设置 → 模型服务 → 用 ChatGPT 账号登录」：系统浏览器打开授权页，授权后 SuDuo 显示已登录（邮箱与套餐）；新开一个会话能正常回答；「退出登录」后显示还没登录。（没有 ChatGPT 账号可以跳过，注明。）
11. 「设置 → 桌面应用 → 打开数据目录 / 打开日志目录」能在资源管理器里打开 `%LOCALAPPDATA%\SuDuo Desktop\data`（及 `logs`）。
12. 退出：右键通知区域图标「退出 SuDuo」；有进行中的会话时先确认，选「取消」不退、选「退出」后进程都结束（任务管理器里没有 SuDuo 和 node）。

## 更新

装好的旧版本本身要带应用内更新（第一个带更新功能的版本或更新的版本；0.10.0 及以前没有）。应用内更新只认 GitHub 上最新的正式 Release，草稿、预发布都看不到，所以第一个带更新功能的版本用本地更新源验：

- 准备一个文件夹，放更高版本的 `SuDuo-Setup-<新版本>-x64.exe`、它的 `.blockmap` 和 `latest.yml`（都从那个版本的构建产物或 Release 附件里拿）。
- 在这个文件夹里起一个本地网页服务，例如 `python -m http.server 8899`（或 `npx http-server -p 8899`）。
- 先退出 SuDuo，在 PowerShell 里带上更新源打开旧版本：`$env:SUDUO_DESKTOP_UPDATE_FEED="http://127.0.0.1:8899/"; & "$env:LOCALAPPDATA\Programs\suduo-desktop\SuDuo.exe"`。

之后的版本发布到正式 Release 后，不设这个变量、直接检查即可。

13. 打开旧版本后在「设置 → 桌面应用」点「检查更新」（或等启动 30 秒后的自动检查）：窗口顶部出现「SuDuo <新版本> 可用 · 更新说明 · 稍后 · 更新」。
14. 开着一个进行中的会话点「更新」：显示下载进度；下完后先确认（会中断进行中的会话）；确认后 SuDuo 退出、静默安装、自动重新打开，版本号变成新版本（「设置 → 桌面应用 → 版本」），数据还在。选「取消」则先不装，再点「更新」不用重新下载。
15. 点「稍后」后这个版本不再提示；重启后也不提示。

## 卸载

16. 「设置 → 应用 → SuDuo → 卸载」：询问是否同时删除本机数据，默认保留；选保留后 `%LOCALAPPDATA%\SuDuo Desktop` 还在，选删除后不在。
