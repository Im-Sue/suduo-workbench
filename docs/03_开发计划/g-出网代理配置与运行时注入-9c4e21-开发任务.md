# G · 出网代理配置与运行时注入

> 本片是批次执行中发现缺陷后、由用户拍板新增的第 14 片，不在原 13 片拆分内。

## 一、任务概述

| 项 | 说明 |
|----|------|
| 交付目标 | 把出网代理做成设置页的一项基础配置，由服务端注入 codex 子进程环境，改完即时生效 |
| 需求来源 | suduo-v2-workbench-ui-refit-001（执行期新增） |
| 触发缺陷 | systemd 下的 SuDuo 不继承 shell 代理，在需代理出网的机器上**完全够不到模型网关** |
| 分工 | ccb_codex（后端与契约）；设置页界面归 pr9 |

## 二、背景

本机实测：

```
带代理：  https://relay.example.com/v1/models → 401（通）
无代理：  curl: (6) Could not resolve host  ← DNS 都解析不出来
```

`client/scripts/install.mjs:46-60` 只写固定 `SUDUO_*` 白名单，不透传任何代理变量，于是 systemd 下的 SuDuo 出网即断，表现为会话发出去没反应、日志里一串 `Reconnecting... N/5`。

**用户 2026-08-17 拍板**：不走"修安装器透传环境变量"，改为**把代理做成设置页的基础配置**——配置属于用户，不该藏在部署脚本里。

## 三、任务分解

1. `SettingsDto` **纯追加** 代理字段（对齐 `maxApprovalMode` 范式），至少含 `httpProxy`、`httpsProxy`、`allProxy`、`noProxy`；空值即不启用。
2. `SettingsService` 持久化与校验：非法 URL 显式报错，不静默丢弃。
3. `runtimeEnvironment()`（`server-application.ts:353`）按设置注入 `HTTP_PROXY`/`HTTPS_PROXY`/`ALL_PROXY`/`NO_PROXY` 及其小写形式；**设置为空时保持进程原有环境变量，不覆盖**。
4. 代理设置变更后调 `codex-runtime.ts:346` 的 `restartConnection(reason)` 使其生效，无需重启服务。
5. 连通性自检端点：用当前（或待保存的）代理试连模型网关，返回可读结果。

## 四、验收标准

- 设置代理后新建会话能正常收发消息（在无代理即不可达的环境上验证）。
- 清空代理后恢复为不注入，进程原有环境变量不被覆盖。
- 变更代理后**无需重启服务**即生效（`restartConnection` 有生产调用者）。
- 非法代理地址被拒并给出可读诊断。
- `/api/v1/settings` 正确返回代理字段。
- server 侧 vitest 覆盖：注入生效、清空恢复、非法值、重启触发。

## 五、边界

- 设置页界面归 **pr9**，本片只做后端与契约，不动 `client/web/src/`。
- 不改 `client/scripts/install.mjs`——安装器透传是另一条路，本片选的是设置页方案，两者不重复做。
- 不动 `CODEX_VERSION` 与协议基线。
- 代理若需鉴权，凭据存储另议，本期只支持无鉴权代理地址。

## 六、风险与注意

| 风险 | 处理 |
|------|------|
| 代理地址写错导致完全不可用 | 提供连通性自检；非法值拒绝保存 |
| 与进程既有代理变量冲突 | 设置为空时不覆盖；非空时以设置为准并在文档写明优先级 |
| `restartConnection` 此前无生产调用者 | 本片是其首个调用方，需覆盖重连后 skill roots 重放路径 |

### 自检端点实测

```
保存态：{"reachable":true,"targetOrigin":"https://relay.example.com","statusCode":401,
        "usingProxy":true,"message":"已到达模型网关（HTTP 401；401/403 仅表示网关仍需 Codex 凭据）"}
草稿态（故意配错端口）：{"reachable":false,"usingProxy":true,"message":"无法连接模型网关：ECONNREFUSED"}
```

把 401 解释为「网关可达、只是缺凭据」这个处理是对的——否则用户会把正常情况误读成失败。

### 实现核验

注入点不在 `runtimeEnvironment()` 而是新增的 `applyProxySettings(target, inherited, settings)`：非空则覆盖，**空值走 `restoreEnvironmentValue()` 还原服务启动时继承的值**，语义正确。

校验限定 `http`/`https`/`socks5`/`socks5h` 四种协议，并**拒绝带鉴权的 URL**——本期不支持代理鉴权，拒绝比默默吞掉凭据好。
