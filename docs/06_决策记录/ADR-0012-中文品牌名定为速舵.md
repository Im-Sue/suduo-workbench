# ADR-0012: 中文品牌名定为「速舵」

> 一个决策一篇，记下「为什么这么定」，防止以后反复扯 / 误改
>
> **状态**：accepted ｜ **拍板人**：用户（2026-10-02：「那就 速舵 吧，被占用了就用 速 就行」）

---

## 一、背景

[ADR-0010](ADR-0010-仓库按客户端云端两端拆分-品牌更名SuDuo.md) 定了英文品牌 SuDuo。产品要面向国内和海外推广（官网、产品界面都做中英双语），国内传播需要一个中文名。用户要求给出中文名，Claude 提了六个候选（速舵、苏舵、速对、速朵、速搭、双舵），并排除了速达（同行业已有「速达软件」）、速度（通用词，不能注册）、速铎（生僻字）。

## 二、决策

1. **中文品牌名为「速舵」**（sù duò），与英文名 SuDuo 并用。
   - 读音与 SuDuo 几乎相同。
   - 寓意「速度交给 AI，方向由人掌舵」，对应「人在回路里、冲突由人裁决」的产品原则（[ADR-0004](ADR-0004-人机协作系统的一致性边界.md)）。
2. **用法**：
   - 中文语境的标题、官网中文页、标志的中文组合写「速舵 SuDuo」或单写「速舵」；英文语境只写 SuDuo。
   - 代码标识符、包名、环境变量、目录名一律保持 ADR-0010 的英文写法，不出现中文名。
3. **被占用时的备选**：上线前在国家知识产权局商标库检索第 9 类（软件）、第 42 类（软件服务）。若「速舵」已被他人注册，按用户原话「被占用了就用 速 就行」改用备选。该原话的具体所指（推测是把「速」换成同音的「苏」，即「苏舵」）**待用户确认**，确认后补记在本 ADR 的第六节。

## 三、否决的方案

| 方案 | 为什么没选 |
|------|------------|
| 苏舵 | 读起来像姓氏品牌，「苏」字不带效率的含义；保留为可能的备选 |
| 速对 | 字面像动词短语（「快速核对」） |
| 速朵 | 自造词最好注册，但气质偏柔，不像开发工具 |
| 速搭 | 与 SuDuo 读音差得多，常用词组合容易被抢注 |
| 双舵 | 与英文名读音对不上 |
| 速达 / 速度 / 速铎 | 同行业已有「速达软件」/ 通用词注册不了 / 「铎」是生僻字 |

## 四、影响

- **好处**：中英两个名字同音，口头传播不需要解释；寓意直接对应产品原则。
- **代价 / 风险**：
  - 「速舵」是含义词，商标注册难度中等，存在已被注册的可能，因此定了备选。
  - 定名后才能开始做印刷物料和正式标志的中文组合。
- **受影响**：
  - 官网中文页面与标志组合；
  - `TRADEMARKS.md`：商标声明要包含中文名；
  - 产品中文界面里出现品牌名的地方：标题、关于页；
  - 品牌视觉画布。
